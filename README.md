# Azure Networking Demo

## Overview
This project demonstrates how to set up a secure Azure networking environment:
- Create a resource group
- Deploy two VNets (hp-vnet and finance-vnet)
- Add subnets and NSGs
- Deploy VMs in each VNet
- Configure bidirectional VNet peering
- Validate connectivity with ping and SSH
